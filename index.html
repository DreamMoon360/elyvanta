Elyvanta AI Studio

A personal tool for the Elyvanta documentary YouTube channel.

Elyvanta AI Studio creates documentary videos and Shorts for the Elyvanta YouTube channel and uploads them to that channel as private videos for review. It is used only by its owner to manage their own channel.

With the channel owner's permission it uses the YouTube Data API and YouTube Analytics API to upload videos, set thumbnails, add captions and playlists, and read the channel's own statistics.
